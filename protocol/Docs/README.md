# Docs

- `convo-protocol-spec-v2.0.md`: the protocol. Parts I–III and Appendices
  A–B are normative; Part IV is how to run a node.
- `deviations.md`: where the reference implementation stands against the
  spec, and what it adds that the spec doesn't have yet.
- `node-api.md`: the operator's reference for the node's endpoints, state,
  ports and environment.

Earlier revisions (v0.10 to v1.0) are archived in AttilaTheFun/convo_crypto.
